# Atlas One v0.8: Environmental Data Architecture

## Overview

The v0.8 release introduces a comprehensive environmental data engine capable of handling varied environmental indicators from multiple external APIs in a standardized, performant manner.

## Key Components

### 1. The `EnvironmentalDataEngine` (Layer 1)
Acts as the central clearinghouse for environmental data.
- **Provider Registry:** External data sources (Open-Meteo, OpenAQ, FIRMS) register as adapters.
- **Polling & Caching:** The engine dictates the polling intervals and caches the normalized `EnvironmentalObservation` data by variable (e.g. Temperature, PM2.5, Wildfires).
- **Unit Normalization:** All inputs are normalized to internal metric SI units using `DataNormalizer` (e.g., Fahrenheit to Celsius, ppm to µg/m³).
- **Validation:** Enforces minimum quality thresholds and removes anomalous bounds data using `DataValidator`.

### 2. Provider Adapters (Layer 2)
Implement the `IEnvironmentalProvider` interface.
- **OpenMeteoWeatherProvider:** Current conditions (temperature, wind, precipitation).
- **OpenAQAirQualityProvider:** PM2.5 and PM10 air quality metrics.
- **FIRMSActiveFireProvider:** NASA FIRMS fire radiative power data.
- **OceanPlaceholderProvider:** Stubbed ocean metrics (Currents, SST) to prevent API key exposure in v0.8.

### 3. Layers & Renderers (Layers 3 & 4)
- **`ILayer` Implementations:** 10 new environmental layers (Temperature, Wind, Air Quality, Vegetation, Flood, etc.) registered in the core `LayerRegistry`.
- **`EnvironmentalLayerRenderer`:** Renders static point data using Cesium's `PointPrimitiveCollection` and `LabelCollection` for extreme performance on global datasets.
- **`WindParticleRenderer`:** Implements an HTML5 canvas overlay for dynamic wind particle animation. Scales particle count based on device performance (mobile vs. desktop).

### 4. Analytics (Layer 5)
- **`EnvironmentalAnalyticsEngine`:** Computes time-series metrics (min, max, mean, moving average, anomalies).
- **`ChangeAnalysis`:** Safely computes scalar and area-based percentage changes over time.
- **`CorrelationEngine`:** Discovers co-located anomalies. **Crucial rule:** Outputs are strictly labeled "Associated Conditions" and never claim causation.

### 5. User Interface (Layer 6)
- **`EnvironmentalDashboard`:** A persistent, collapsible HUD element showing key 7 indicators (toggle via 'E' key).
- **`ClimateAnalyticsPanel`:** A 2D canvas charting interface for time-series trend visualization and delta statistics.
- **`EnvironmentalLegendPanel`:** A reactive legend that updates based on the active environmental layer, rendering linear gradients and indicating `DataState` (Live, Historical, Simulated).

### 6. AI Command Engine (Layer 7)
Integrated 15 new `AITool` definitions allowing users to query environmental metrics via natural language. 
- Example: "What's the air quality in London?" triggers the `queryAirQuality` tool, which automatically enables the Air Quality layer and retrieves PM2.5 data from the engine.
